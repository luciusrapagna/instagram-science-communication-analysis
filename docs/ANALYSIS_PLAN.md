# Statistical Analysis Plan

## Study design

This is an observational, retrospective, quantitative study of 187 Instagram
posts published by two university extension projects between April and July
2026.

The unit of analysis is one Instagram post.

## Projects

- Ocean Culture: 93 posts
- PsicoCampus: 94 posts

## Post formats

- Image
- Carousel
- Reel

The format distribution is unbalanced across projects. In particular, Ocean
Culture includes only one Reel. Therefore, project and post-format effects
cannot be treated as fully independent without caution.

## Outcomes

Primary performance outcomes:

- Views
- Reach
- Likes
- Shares
- Comments
- Saves
- Follows
- Total interactions

Total interactions are defined as:

    likes + shares + comments + saves

Follows are analyzed as a separate outcome.

## Missing-data rule

Missing values will not be replaced with zero.

Analyses will use available observations for each outcome:

- Reach: n = 185
- Follows: n = 185
- All other outcomes: n = 187

The two missing reach values and the two missing follow values occur in the
same two Ocean Culture image posts.

## Descriptive analysis

For every outcome, report:

- Valid sample size
- Median
- First quartile
- Third quartile
- Interquartile range
- Minimum
- Maximum

Means and standard deviations may be retained for supplementary description,
but medians and interquartile ranges are the primary summaries because the
outcomes are asymmetric, contain extreme values, and several engagement
variables have a high proportion of zeros.

## Comparison between projects

Ocean Culture and PsicoCampus will be compared using the two-sided
Mann-Whitney U test for each outcome.

For every comparison, report:

- Sample size in each group
- Median and interquartile range
- Mann-Whitney U statistic
- Unadjusted p-value
- Multiplicity-adjusted p-value
- Rank-biserial effect size

The family of eight project comparisons will be adjusted using the Holm
method.

## Comparison between post formats

Image, Carousel, and Reel posts will first be compared using the
Kruskal-Wallis test.

When the omnibus test indicates evidence of differences, pairwise
Mann-Whitney U comparisons will be conducted with Holm adjustment.

Format results must be interpreted cautiously because formats are unevenly
distributed between projects and Ocean Culture contains only one Reel.

## Associations between outcomes

Associations among performance outcomes will be estimated using Spearman rank
correlations.

For every pair, report:

- Number of complete observation pairs
- Spearman rho
- Unadjusted p-value
- Holm-adjusted p-value

Correlation does not establish causality, and mathematically overlapping
variables require special caution. Total interactions should not be treated as
independent of likes, shares, comments, or saves because it is calculated from
those variables.

## Statistical conventions

- Tests are two-sided.
- The nominal significance level is 0.05.
- Exact sample sizes are reported for every analysis.
- Effect sizes and uncertainty receive priority over binary significance
  labels.
- Missing data, zero inflation, multiplicity, and unbalanced format
  distributions are reported transparently.

## Reproducibility

Raw data remain unchanged in `data/raw`.

Standardized data are generated by `scripts/02_prepare_data.py`.

All tables and figures must be generated from scripts and written to the
`outputs` directory.
