# CPIF Figure Caption

**Figure 1. Communication Performance Interpretation Framework (CPIF).** The framework comprises six iterative analytical layers: (1) Communication Context, (2) Platform-recorded Metrics, (3) Metric Preparation and Standardisation, (4) Statistical Integration, (5) Communication-performance Interpretation, and (6) Evidence-informed Decision Support. Although presented sequentially, the workflow is iterative, allowing previous analytical stages to be revisited whenever additional evidence, contextual information, or methodological refinement is required.
