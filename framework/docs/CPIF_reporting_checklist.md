# CPIF reporting checklist

This checklist supports transparent reporting of studies applying the Communication Performance Interpretation Framework. “To assess” indicates that correspondence with the current manuscript has not yet been verified.

| Domain | Item | Required information | Reported in study? | Location in manuscript | Notes |
|---|---|---|---|---|---|
| Communication context | Initiative and objectives | Type, scope, institutional setting, and communication objectives | To assess | To map | |
| Communication context | Platform | Platform name, account context, data source, and relevant platform conditions | To assess | To map | |
| Communication context | Audience | Intended audience and available information about observed audiences | To assess | To map | |
| Communication context | Observation period | Beginning and end of the observation period | To assess | To map | |
| Communication context | Extraction date | Date on which platform metrics were extracted | To assess | To map | |
| Communication context | Cumulative exposure | Publication dates, time at risk, and handling of unequal exposure periods | To assess | To map | |
| Communication context | Paid promotion | Whether distribution was organic, paid, boosted, mixed, or unknown | To assess | To map | |
| Communication context | Unit of analysis | Definition of the observational unit and relevant nesting or repeated observations | To assess | To map | |
| Platform-recorded metrics | Metric definitions | Platform-specific definitions, counting units, and distinction between events and unique accounts | To assess | To map | |
| Platform-recorded metrics | Construct mapping | Justified primary and, where relevant, secondary analytical role of each metric, including ambiguity and attribution windows | To assess | To map | |
| Metric preparation | Missing data | Extent of missingness and rules distinguishing missing values from true zeros | To assess | To map | |
| Metric preparation | Derived indicators | Numerators, denominators, multipliers, validity rules, treatment of zero denominators, and whether indicators count repeatable events rather than proportions of users | To assess | To map | |
| Statistical integration | Analysis plan | Research questions, estimands or descriptive targets, outcomes, comparisons, stratification, assumptions, and software | To assess | To map | |
| Statistical integration | Effect sizes | Effect-size definitions, direction, magnitude, and uncertainty when estimable | To assess | To map | |
| Statistical integration | Multiplicity | Inferential family, correction method, and distinction between confirmatory and exploratory analyses | To assess | To map | |
| Statistical integration | Sensitivity analysis | Analytical decisions varied, rationale, and stability of conclusions | To assess | To map | |
| Statistical integration | Dependence or clustering | Potential nesting, repeated observations, temporal dependence, and analytical handling | To assess | To map | |
| Interpretation | Limitations | Design, measurement, platform, sample, temporal, and generalizability limitations | To assess | To map | |
| Open Science | Data, code, and documentation | Availability, repository, versions, licenses, restrictions, and reproducibility materials | To assess | To map | |
| Ethics and governance | Responsible data use | Privacy, ethics review or justification, platform terms, legal constraints, and protections for account or user information | To assess | To map | |
| Interpretation | Performance versus effectiveness | Explicit statement that platform metrics provide proxy evidence about exposure and interaction but not direct educational or societal effectiveness | To assess | To map | |
| Decision support | Bounded use of findings | Proposed decision or hypothesis, supporting evidence, uncertainty, responsible actor, and prospective evaluation plan | To assess | To map | |
