# CPIF Reporting Checklist

## Communication context

- [ ] Communication objective stated
- [ ] Target audience described
- [ ] Platform and account characteristics reported
- [ ] Observation period and publication frequency reported
- [ ] Organic and paid distribution distinguished
- [ ] Content themes and formats described

## Metrics

- [ ] Metrics classified as exposure, interaction, audience growth, or derived
- [ ] Platform definitions documented
- [ ] Numerators and denominators stated for rates
- [ ] Total interactions decomposable into component metrics

## Data preparation

- [ ] Analytical sample size reported
- [ ] Missing data reported
- [ ] Duplicates assessed
- [ ] Category harmonisation documented
- [ ] Outlier handling documented
- [ ] Audit script or equivalent available

## Statistical integration

- [ ] Distributional characteristics examined
- [ ] Statistical tests justified
- [ ] Effect sizes reported
- [ ] Multiple comparisons addressed
- [ ] Sensitivity analyses considered
- [ ] Software and package versions reported

## Interpretation

- [ ] Exposure and interaction interpreted separately
- [ ] Statistical significance distinguished from practical relevance
- [ ] Correlation not interpreted causally
- [ ] Platform and observational limitations stated
- [ ] Claims do not exceed measured outcomes

## Decision support

- [ ] Recommendations linked to specific evidence
- [ ] Evidence strength and uncertainty stated
- [ ] Additional data needs identified
- [ ] Reproducibility materials referenced
